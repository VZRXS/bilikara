## 交付范围与架构

- 共享 Host 滚动公告板、设置入口、自动一次展示和手动历史查看、中英日界面、安全 Markdown 子集、固定关闭按钮、键盘焦点约束和 Android 返回键。
- `rust/announcement_policy`：纯、确定性的筛选与排序，外部提供时钟/安装版本/平台/已展示 ID，无网络或文件 IO。
- `rust-runtime/announcements`：有限大小的 JSON 校验、R2 静态 HTTP、ETag/短缓存、原子文件持久化；唯一 mutable State 存在 AppState 的 NativeSession 中。HTTP 下载不持有 AppState 锁。原生 Host 路由要求 Host 身份，不向 Remote 暴露轮询/记录修改权限。
- Tauri/Android：只提供可信的实际 APK 版本名称和窗口返回键操作。使用 Gradle 的 VERSION_NAME，不能拿 Tauri 基础 SemVer 代替预览包版本。
- 没有新增或修改 Python 业务规则，没有 Python fallback，没有数据库迁移。
- 依照 Cloudflare 技能采用 R2 单文件、内联正文、短缓存、ETag 和合并请求；不引入 D1，也不把 ETag 误算成零计费请求。详见 [发布与请求量说明](announcements.md)。
