## Experimental automatic volume

The shared Rust runtime uses [ebur128 0.1.10](https://github.com/sdroege/ebur128)
(MIT) to measure integrated loudness from the existing in-process libav decoder.
Only integrated mode and its bounded histogram are used; no true-peak or LRA
scan. Default Cargo features are disabled. The upstream license is retained in
`third_party/ebur128-LICENSE.txt` and packaged in
`license/THIRD_PARTY_LICENSES/ebur128-LICENSE.txt`.

## Native YouTube quick requests

The shared Rust runtime uses `rquickjs` **0.14.0** and its bundled QuickJS-NG
engine (MIT) for bounded, in-process YouTube signature computation, plus the
fixed **yt-dlp EJS 0.8.0** solver (Unlicense). EJS includes Meriyah 6.1.4 (ISC)
and astring 1.9.0 (MIT). It does not bundle or launch the yt-dlp executable or
Python, Node or Deno. HTTP extraction and transfer remain Rust-owned.

The complete upstream license texts are in `static/youtube-native-LICENSES.txt`,
shipped with the desktop static assets and Android embedded assets. EJS source,
provenance and checksums are in `rust-runtime/vendor/yt-dlp-ejs/`.
Supported input and playback limits are documented in `docs/quick-start.md`;
build requirements are in `docs/native-desktop.md`.

## QR image generation

Internet Remote and login QR PNGs are generated by `bilikara_runtime` using
[`qrcode` 0.14.1](https://github.com/kennytm/qrcode-rust) and
[`png` 0.18.1](https://github.com/image-rs/image-png), both MIT OR Apache-2.0.
Both dependencies disable default features. P03 reuses the same QR encoder for
playlist/history footers. Python `qrcode` and Pillow are no longer production
dependencies. The replaced Pillow test decoder and preview-script tool are retired.

Playlist/history rendering uses [COSMIC Text 0.17](https://github.com/pop-os/cosmic-text)
(MIT OR Apache-2.0), including fontdb, HarfRust and Swash for font discovery,
shaping, variable font weights and rasterization. The bundled Source Han Sans
font remains primary; installed system fonts supply fallback without downloads.
[chrono](https://github.com/chronotope/chrono) (MIT OR Apache-2.0) formats local
time; [csv](https://github.com/BurntSushi/rust-csv) (MIT OR Unlicense) writes CSV.
The existing `png` and `zip` crates encode sequential image pages and archives.
The independent [quircs](https://github.com/dignifiedquire/quircs) decoder
(MIT, 0.10.3) is a Rust test-only dependency. It is not linked into the Host,
updater or desktop build tool.

Native Host camera/image import decodes QR codes locally with
[rxing 0.9.3](https://github.com/rxing-core/rxing), a pure Rust port of ZXing
with QR enhancements ported from zxing-cpp (Apache-2.0). Only QR decoding,
multiple-code detection and character encoding support are enabled; image
codecs, encoders and other barcode formats are excluded.

packages contain no Python runtime, PyInstaller payload or truststore module.

These historical tools' licenses apply if distributing the corresponding
legacy product, rather than making them dependencies of the native package.
